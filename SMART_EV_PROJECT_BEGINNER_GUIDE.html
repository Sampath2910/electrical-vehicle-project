⚡ Smart EV Charging Station Platform

Beginner-Friendly Installation, Build, and Operations Guide

Project Title: Smart EV Charging Station: Time-of-Day (ToD) Tariff & Priority Preemption System
Target Application: Electric Two-Wheelers (1.0 kW to 3.3 kW Single-Phase AC)
Status: Live & Running Locally on Port 3000 (Frontend) and Port 8080 (Backend)
Guide Prepared For: Beginners, Teammates, and Project Evaluators

📌 1. Project Overview & Key Features

This project is a complete IoT-enabled Smart Electric Two-Wheeler (2W) Charging Infrastructure Platform. It addresses power quality monitoring, dynamic time-based electricity tariffs, priority emergency eviction, and dynamic Bharat-QR/UPI payments.

Core Features:

  • Time-of-Day (ToD) Tariff System (Commercial LT-6):
    • Off-Peak (10 PM – 6 AM) ₹8.00 / kWh (S₁) — Lowest tariff tier when grid demand is minimal.
    • Standard (6 AM – 6 PM) ₹10.50 / kWh (S₂) — Daytime solar & standard rate.
    • Peak (6 PM – 10 PM) ₹14.00 / kWh (S₃) — Evening grid surcharge.
  • Priority Preemption Eviction Protocol (KLETECH EV Station 2):
    • Dedicated VIP / Emergency Bay with ₹8.00/kWh surge premium.
    • Active 120-second eviction countdown upon emergency vehicle arrival.
    • Automatic hardware relay trip and ₹500 penalty if not unplugged within 120s.
  • 2W Metrology Engine (PZEM-004T AC Sensor):
    • Real-time single-phase AC measurements (Voltage 230V, Current ≤ 14.3A, Active Power kW, Power Factor 0.98, THD 2.1%).
    • Vehicle Presets: Ather 450X (3.7 kWh), Ola S1 Pro (4 kWh), TVS iQube (3.4 kWh), Ultraviolette F77 (10.3 kWh), Revolt RV400 (3.24 kWh).
  • Dynamic Bharat-QR & UPI Gateway:
    • Instant QR generation for GPay, PhonePe, Paytm, or BHIM UPI upon session completion.

🚀 4. Step-by-Step Terminal Commands (Beginner Guide)

Step 1: Extract Zip File

# Open PowerShell in the zip folder
Expand-Archive -Path "electrical-vehicle-project-main (1).zip" -DestinationPath "." -Force
cd "electrical-vehicle-project-main"

Step 2: Configure Environment Variables

cd frontend
Set-Content -Path ".env.local" -Value @"
NEXT_PUBLIC_API_URL=http://localhost:8080
NEXT_PUBLIC_WS_URL=ws://localhost:8080/ws-ev
NEXT_PUBLIC_DATA_MODE=mock
"@

Step 3: Install Frontend Packages

# Run inside frontend folder
npm install

Step 4: Compile Backend Server

# Open new PowerShell window in backend folder
cd "electrical-vehicle-project-main\backend"
mvn clean compile

Step 5: Launch Backend Server (Port 8080)

mvn spring-boot:run

Step 6: Launch Frontend Server (Port 3000)

# Open new PowerShell window in frontend folder
cd "electrical-vehicle-project-main\frontend"
npm run dev

Step 7: Access Application in Browser

Open browser at: http://localhost:3000

🧮 5. Billing Formula & Example Calculation

$$\text{Total Amount} = (\text{kWh} \times \text{ToD Rate}) + \text{Service Fee (₹5.00)} + 18\% \text{ GST} + (\text{Emergency Penalty ₹500 if applicable})$$

Example Calculation (Ather 450X - 3.0 kWh during Peak Hours S₃):

  • Energy Cost = 3.0 kWh × ₹14.00 = ₹42.00
  • Service Fee = ₹5.00
  • Subtotal = ₹47.00
  • GST (18%) = ₹8.46
  • Total Payable = ₹55.46
